# Scoped Plan

调查指定范围，生成实施计划；不要修改项目文件或执行计划。

最终回复只能包含一个 Markdown 围栏代码块，代码块外不要输出任何内容。代码块内按以下结构编写：
# 任务名称

## 目标

## 当前实现与问题分析

## 修改范围

- 主要修改文件
- 可能的关联文件
- 保持不变或不应修改的范围

## 实施步骤


按执行顺序列出具体步骤，并注明涉及的文件、符号或配置。

## 验证步骤

## 验收标准

## 风险与待确认事项

删除不适用的小节。不要编造未确认的实现细节；将会影响方案的信息列为待确认事项。

若代码块内需要展示命令、代码或伪代码，使用四个空格缩进，不嵌套围栏代码块。
