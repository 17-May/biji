# Scoped Plan

读取用户提供的目录及其子目录，分析用户提出的问题。

只生成计划方案，不执行计划或修改文件。

计划应体现分析逻辑、实施步骤和验证方法。

严格遵守以下输出格式：

- 整个最终回复必须且只能包含一个 Markdown 围栏代码块。
- 回复的第一个字符必须是代码围栏的反引号，最后一个字符必须是结束代码围栏的反引号。
- 所有标题、说明、计划、待确认事项和其他内容都必须放在该代码块内。
- 代码块外不得输出前言、总结、提示或任何其他字符。
- 即使信息不足或无法生成完整计划，也必须在同一个代码块内说明。
- 不要在外层代码块内部使用三个反引号；需要展示命令或代码时，使用四个空格缩进。
