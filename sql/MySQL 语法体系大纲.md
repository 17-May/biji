
整体分为**基础模块、DDL、DML、DQL、DCL、事务与锁、函数、存储程序、高级特性、运维管理**十大板块，贴合高校《数据库原理与设计》课程教学体系。

## 一、MySQL 基础入门语法

1. 登录与退出命令
2. 客户端基础操作指令
3. 注释、标识符、关键字、常量与变量
4. 数据类型体系：数值、字符串、日期时间、二进制、特殊类型
5. 运算符：算术、比较、逻辑、位运算、赋值、区间、模糊匹配

## 二、数据定义语言 DDL

1. 数据库操作：创建、查看、修改、删除、切换数据库
2. 数据表操作：创建、查看、修改、重命名、删除表
3. 完整性约束：主键、外键、唯一、非空、默认值、检查约束
4. 索引操作：普通索引、唯一索引、主键索引、全文索引、复合索引（增 / 查 / 删）
5. 视图操作：视图创建、修改、查看、删除
6. 自增列、临时表、表分区相关语法

## 三、数据操纵语言 DML

1. 数据插入：单行插入、多行批量插入、查询结果插入
2. 数据更新：单表更新、多表联合更新
3. 数据删除：普通删除、清空表、多表联合删除

## 四、数据查询语言 DQL

1. 基础 SELECT 单表查询
2. 字段筛选、别名、去重、行数限制
3. 条件查询 `WHERE`、排序 `ORDER BY`
4. 聚合函数、分组 `GROUP BY`、分组过滤 `HAVING`
5. 多表连接：内连接、左外连接、右外连接、全连接、交叉连接
6. 子查询：标量子查询、行 / 列 / 表子查询、相关子查询
7. 联合查询 `UNION` / `UNION ALL`
8. 分页查询、衍生表查询

## 五、数据控制语言 DCL

1. 用户管理：创建、修改、删除用户
2. 权限授予 `GRANT`
3. 权限撤销 `REVOKE`
4. 密码修改、账户锁定、权限查看
5. 角色管理（高版本 MySQL）
