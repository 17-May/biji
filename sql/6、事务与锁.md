### 6.1 事务基础：开启、提交、回滚

``` sql
-- 显式开启事务
START TRANSACTION;
-- 等价写法
BEGIN;

-- 提交事务（所有操作持久化生效）
COMMIT;

-- 回滚事务（撤销所有未提交操作）
ROLLBACK;
```

### 6.2 事务保存点

``` sql
-- 创建保存点
SAVEPOINT 保存点名;

-- 回滚到指定保存点，不影响保存点之前的操作
ROLLBACK TO SAVEPOINT 保存点名;

-- 删除保存点
RELEASE SAVEPOINT 保存点名;
```

### 6.3 事务隔离级别配置

My sql 隔离级别：**READ UNCOMMITTED、READ COMMITTED、REPEATABLE READ、SERIALIZABLE**

``` sql
-- 查看当前会话隔离级别
SELECT @@tx_isolation;
SELECT @@transaction_isolation;

-- 查看全局隔离级别
SELECT @@global.transaction_isolation;

-- 设置当前会话隔离级别
SET SESSION TRANSACTION ISOLATION LEVEL 隔离级别名;

-- 设置全局隔离级别（重启生效，需管理员权限）
SET GLOBAL TRANSACTION ISOLATION LEVEL 隔离级别名;

-- 示例
SET SESSION TRANSACTION ISOLATION LEVEL READ COMMITTED;
```

### 6.4 隐式 / 显式事务设置

``` sql
-- 查看自动提交状态（1=隐式事务，0=显式事务）
SELECT @@autocommit;

-- 开启自动提交（默认，隐式事务，单条 sql自动提交）
SET autocommit = 1;

-- 关闭自动提交（显式事务，需手动 COMMIT/ROLLBACK）
SET autocommit = 0;
```

### 6.5 基础锁操作：表锁、行锁

#### 6.5.1 表级锁（MyISAM 常用）

``` sql
-- 加读锁（共享锁），所有会话可读，当前会话可读写，其他会话不可写
LOCK TABLES 表名 READ;

-- 加写锁（排他锁），仅当前会话可读写，其他会话全部阻塞
LOCK TABLES 表名 WRITE;

-- 释放表锁
UNLOCK TABLES;
```

#### 6.5.2 行级锁（InnoDB 引擎，依赖事务）

行锁默认自动触发，需在事务中使用

``` sql
-- 手动添加行级排他锁（SELECT ... FOR UPDATE）
BEGIN;
SELECT * FROM 表名 WHERE 条件 FOR UPDATE;
COMMIT; -- 提交后自动释放行锁

-- 手动添加行级共享锁（SELECT ... LOCK IN SHARE MODE）
BEGIN;
SELECT * FROM 表名 WHERE 条件 LOCK IN SHARE MODE;
COMMIT; -- 提交后自动释放行锁
```

#### 6.5.3 查看锁状态

``` sql
-- 查看当前锁、等待事务
SHOW ENGINE INNODB STATUS;

-- 查询锁相关元数据（My sql 8.0+）
SELECT * FROM performance_schema.data_locks;
```
