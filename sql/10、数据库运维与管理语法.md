### 10.1 运行状态查看、会话 / 全局变量配置

#### 10.1.1 运行状态查看

``` sql
-- 查看服务器整体状态信息
SHOW STATUS;
-- 查看会话级状态
SHOW SESSION STATUS;
-- 查看全局级状态
SHOW GLOBAL STATUS;

-- 查看当前连接、线程信息
SHOW PROCESSLIST;
-- 查看完整 sql语句（完整进程列表）
SHOW FULL PROCESSLIST;

-- 终止指定连接线程
KILL 线程ID;
```

#### 10.1.2 系统变量查看与配置

``` sql
-- 查看所有系统变量
SHOW VARIABLES;
-- 模糊查询指定变量
SHOW VARIABLES LIKE '变量名%';

-- 查看会话级变量值
SELECT @@会话变量名;
-- 查看全局变量值
SELECT @@global.变量名;

-- 设置会话级变量（当前连接生效，重启失效）
SET 变量名 = 新值;
SET SESSION 变量名 = 新值;

-- 设置全局变量（新连接生效，重启失效，需权限）
SET GLOBAL 变量名 = 新值;
```

### 10.2 日志相关操作指令

``` sql
-- 查看日志相关变量配置
SHOW VARIABLES LIKE '%log%';

-- 查看二进制日志（binlog）列表
SHOW BINARY LOGS;
-- 查看当前正在使用的binlog文件
SHOW MASTER STATUS;

-- 刷新日志（生成新日志文件）
FLUSH LOGS;

-- 清空所有二进制日志（慎用）
RESET MASTER;

-- 慢查询日志查看（文本形式，需结合文件查看）
-- 查看慢查询开关与路径
SHOW VARIABLES LIKE 'slow_query_log';
SHOW VARIABLES LIKE 'slow_query_log_file';

-- 错误日志、通用查询日志：通过对应系统变量查看存储路径
SHOW VARIABLES LIKE 'log_error';
SHOW VARIABLES LIKE 'general_log';
```

### 10.3 数据库备份、恢复基础命令

> 以下为 **my sqldump / my sql** 客户端命令（在系统命令行执行，非  sql 终端）

#### 10.3.1 数据备份 my sqldump

bash

运行

```
# 1. 备份单个数据库
my sqldump -u用户名 -p密码 数据库名 > 备份文件路径. sql

# 2. 备份单库中指定数据表
my sqldump -u用户名 -p密码 数据库名 表名1 表名2 > 备份文件路径. sql

# 3. 备份所有数据库
my sqldump -u用户名 -p密码 --all-databases > 全库备份. sql

# 4. 仅备份表结构，不备份数据
my sqldump -u用户名 -p密码 -d 数据库名 > 仅结构备份. sql

# 5. 仅备份数据，不备份表结构
my sqldump -u用户名 -p密码 -t 数据库名 > 仅数据备份. sql
```

#### 10.3.2 数据恢复

bash

运行

```
# 方式1：命令行恢复（指定数据库）
my sql -u用户名 -p密码 目标数据库名 < 备份文件路径. sql

# 方式2：My sql客户端内执行导入
SOURCE 备份文件绝对路径;
```

### 10.4 表修复、分析、优化指令

#### 10.4.1 检查表

``` sql
-- 检查表状态、错误（支持 MyISAM/InnoDB）
CHECK TABLE 表名;
CHECK TABLE 表名1, 表名2;
```

#### 10.4.2 修复表（主要用于 MyISAM 引擎）

``` sql
-- 常规修复表
REPAIR TABLE 表名;
-- 快速修复
REPAIR TABLE 表名 QUICK;
-- 强制修复（丢失部分数据风险，谨慎使用）
REPAIR TABLE 表名 FORCE;
```

#### 10.4.3 分析表（更新索引统计信息，优化执行计划）

``` sql
ANALYZE TABLE 表名;
ANALYZE TABLE 表名1, 表名2;
```

#### 10.4.4 优化表（整理碎片、释放空间、重组索引）

``` sql
-- 优化表，InnoDB/MyISAM 均支持
OPTIMIZE TABLE 表名;
OPTIMIZE TABLE 表名1, 表名2;
```
