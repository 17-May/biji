### 8.1 存储过程

#### 8.1.1 创建存储过程

``` sql
-- 语法模板
DELIMITER $$
CREATE [PROCEDURE] 存储过程名([IN/OUT/INOUT 参数名 数据类型,...])
BEGIN
    -- 过程体  sql 逻辑
END $$
DELIMITER ;

-- 示例：入参查询
DELIMITER $$
CREATE PROCEDURE proc_query(IN id INT)
BEGIN
    SELECT * FROM student WHERE student.id = id;
END $$
DELIMITER ;
```

#### 8.1.2 调用存储过程

``` sql
CALL 存储过程名(实参列表);

-- 示例
CALL proc_query(1);
```

#### 8.1.3 修改存储过程

My sql 不支持直接修改过程体，需先删除再重建；仅可修改注释等属性

``` sql
ALTER PROCEDURE 存储过程名 COMMENT '新注释';
```

#### 8.1.4 删除存储过程

``` sql
DROP PROCEDURE 存储过程名;
DROP PROCEDURE IF EXISTS 存储过程名;
```

#### 8.1.5 查看存储过程

``` sql
-- 查看库内所有存储过程
SHOW PROCEDURE STATUS WHERE Db = '数据库名';
-- 查看创建语句
SHOW CREATE PROCEDURE 存储过程名;
```

### 8.2 触发器

#### 8.2.1 创建触发器

``` sql
-- 语法模板
DELIMITER $$
CREATE TRIGGER 触发器名
触发时机(BEFORE/AFTER) 触发事件(INSERT/UPDATE/DELETE)
ON 表名 FOR EACH ROW
BEGIN
    -- 触发执行逻辑
END $$
DELIMITER ;

-- 示例：插入后触发
DELIMITER $$
CREATE TRIGGER tri_stu_insert
AFTER INSERT ON student FOR EACH ROW
BEGIN
    INSERT INTO log_table(content) VALUES('新增学员数据');
END $$
DELIMITER ;
```

#### 8.2.2 查看触发器

``` sql
-- 查看所有触发器
SHOW TRIGGERS;
-- 查看指定库触发器
SHOW TRIGGERS LIKE '表名';
-- 查看创建语句
SHOW CREATE TRIGGER 触发器名;
```

#### 8.2.3 删除触发器

``` sql
DROP TRIGGER 触发器名;
DROP TRIGGER IF EXISTS 触发器名;
```

### 8.3 事件调度器（定时任务）

#### 8.3.1 开启 / 关闭事件调度器

``` sql
-- 查看状态
SHOW VARIABLES LIKE 'event_scheduler';
-- 开启
SET GLOBAL event_scheduler = ON;
-- 关闭
SET GLOBAL event_scheduler = OFF;
```

#### 8.3.2 创建事件

``` sql
-- 语法模板
CREATE EVENT 事件名
ON SCHEDULE 调度规则
[ENABLE/DISABLE]
DO
BEGIN
    -- 定时执行逻辑
END;

-- 示例1：一次性事件，指定时间执行
CREATE EVENT event_once
ON SCHEDULE AT '2026-12-31 23:59:59'
DO
INSERT INTO log_table(content) VALUES('定时执行日志');

-- 示例2：周期性事件，每隔1分钟执行
CREATE EVENT event_cycle
ON SCHEDULE EVERY 1 MINUTE
DO
TRUNCATE TABLE temp_table;
```

#### 8.3.3 查看事件

``` sql
SHOW EVENTS;
SHOW EVENTS LIKE '事件名';
```

#### 8.3.4 修改事件状态与调度

``` sql
-- 启用事件
ALTER EVENT 事件名 ENABLE;
-- 禁用事件
ALTER EVENT 事件名 DISABLE;
-- 修改执行逻辑
ALTER EVENT 事件名 DO 新 sql语句;
```

#### 8.3.5 删除事件

``` sql
DROP EVENT 事件名;
DROP EVENT IF EXISTS 事件名;
```

### 8.4 流程控制语句

#### 8.4.1 IF 语句

``` sql
-- 单分支
IF 条件 THEN
    语句体;
END IF;

-- 双分支
IF 条件 THEN
    语句体1;
ELSE
    语句体2;
END IF;

-- 多分支
IF 条件1 THEN
    语句体1;
ELSEIF 条件2 THEN
    语句体2;
ELSE
    语句体3;
END IF;
```

#### 8.4.2 CASE 语句

``` sql
-- 等值匹配
CASE 变量/字段
WHEN 值1 THEN 语句1;
WHEN 值2 THEN 语句2;
ELSE 语句3;
END CASE;

-- 条件匹配
CASE
WHEN 条件1 THEN 语句1;
WHEN 条件2 THEN 语句2;
ELSE 语句3;
END CASE;
```

#### 8.4.3 LOOP 循环（死循环，配合 LEAVE 退出）

``` sql
循环标签: LOOP
    循环体;
    IF 退出条件 THEN
        LEAVE 循环标签;
    END IF;
END LOOP 循环标签;
```

#### 8.4.4 WHILE 循环（先判断后执行）

``` sql
WHILE 循环条件 DO
    循环体;
END WHILE;
```

#### 8.4.5 REPEAT 循环（先执行后判断，至少执行一次）

``` sql
REPEAT
    循环体;
UNTIL 退出条件
END REPEAT;
```

### 8.5 游标使用语法

游标用于逐行读取查询结果，仅用于存储过程 / 函数 / 触发器

``` sql
-- 1. 声明游标
DECLARE 游标名 CURSOR FOR SELECT 字段 FROM 表名 WHERE 条件;

-- 2. 打开游标
OPEN 游标名;

-- 3. 读取游标数据（存入变量）
FETCH 游标名 INTO 变量1, 变量2;

-- 4. 关闭游标
CLOSE 游标名;

-- 5. 释放游标（会话结束自动释放，可不手动执行）
DECLARE CONTINUE HANDLER FOR NOT FOUND SET 标记变量 = 1;

-- 完整示例框架
DELIMITER $$
CREATE PROCEDURE proc_cursor()
BEGIN
    -- 定义变量
    DECLARE v_id INT;
    DECLARE v_name VARCHAR(20);
    DECLARE flag INT DEFAULT 0;
    -- 声明游标
    DECLARE cur_stu CURSOR FOR SELECT id,name FROM student;
    -- 捕获无数据异常
    DECLARE CONTINUE HANDLER FOR NOT FOUND SET flag = 1;
    -- 打开游标
    OPEN cur_stu;
    -- 循环读取
    WHILE flag = 0 DO
        FETCH cur_stu INTO v_id, v_name;
        SELECT v_id, v_name;
    END WHILE;
    -- 关闭游标
    CLOSE cur_stu;
END $$
DELIMITER ;
```
