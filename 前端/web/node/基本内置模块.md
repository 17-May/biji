# 基本内置模块

# os

- EOL：分割符（\r\n）,不同系统不一样
- arch()：cpu架构名（x32/x64）
- **cpus()** ：获取cpu内核
- freemem()：获取空闲内存（字节）
- homedir()：获取用户目录（C:\Users\Administrator）
- hostname()：获取主机名
- **tmpdir()** ：获取临时目录

# path

- basename(url,后缀名)：获取路径的文件名，后缀名匹配成功则去掉
- sep：分割符（\\）
- delimiter：分割符（；），环境变量中使用
- dirname(url)：获取路径，不要文件名
- extname(url )：获取文件后缀名
- join()：将多段路径拼接
- normalize(url)：路径规范化
- relative(url1,url2)：路径2相对于路径1的相对路径
- resolve(url)：相对于命令行（指定地址）生成绝对路径

# url

- URL：获取url地址的信息

# util

- callbackify：将异步函数转换成callbackify函数
- promisify：将回调模式转换成异步函数
- isDeepStrictEqual：将两个对象深度严格比较
