# 模块化细节

# 模块的查找

- 绝对路径
- 相对路径 ./ 或者 ../
  - 转换成绝对路径
- 相当路径
  - 检查是否是内置模块，如fs、path等
  - 检查当前目录中的node-modules
  - 检查上级目录中的node-modules
  - 转换成绝对路径
- 关于后缀名
  - 自动补全后缀名。js、json、node、mjs
- 关于文件名
  - 如果仅提供目录，不提供文件名，则自动寻找目录中的index.js
  - package.json中的main字段
    - 包的默认入口
    - 导入或者执行包时若仅提供目录，则使用main补全入口
    - 默认值为index.js

# require对象

如果module.exports重新赋值后，exports和this都无效

```js
function require() {
  module.exports = {};
  const exports = module.exports;
  xx.call(module.exports);//this实际上是exports

  return module.exports;
}
```
