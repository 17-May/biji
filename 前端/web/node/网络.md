# 网络

# net(通信模块)

##### http请求

- 普通模式：三次握手-请求响应-四次挥手
- 长连接模式（keep-alive）：三次握手-各种数据传输-四次挥手

### 作用

- 进程间的通信IPC
- 网络通信 TCP/IP

### 创建连接

`net.createConnection({path,host},()=>{})` 返回一个socket

##### socket

- 是一个特殊的文件
- 在node中是一个双工流对象
- 通过向流写入内容发送数据
- 通过监听流的内容获取数据

### 创建服务器

`net.createServer(()=>{})` 创建服务
`server.listen(port,()=>{})` 监听端口

# http模块（80）

### 请求

`http.request(path[,options],callback)`

```js
const http = require("http");
const request = http.request(
  "http://127.0.0.1:8000/user/test",
  {
    method: "GET",
  },
  (res) => {
    console.log("请求状态码：", res.statusCode);
    console.log("请求头部：", res.headers);
    // 监听数据 以流的形式
    let data = "";
    res.on("data", (chunk) => {
      data += chunk;
    });
    res.on("end", () => {
      console.log("响应数据：", data);
    });
  }
);
request.end(); //发送消息体，消息体结束
```

### 创建服务器

`http.createServer([options],requestListener())`

```js
const http = require("http");
const path = require("path");
const fs = require("fs");
const server = http.createServer();
server.on("request", (req, res) => {
  const pathname = req.url;
  req.setHeader(
    "Cacche-Control",
    "public, max-age=31536000" //public表示可以被缓存，max-age=31536000表示缓存时间为一年
  );
  if (path.extname(pathname) === ".html") {
    res.setHeader("Content-Type", "text/html");
    fs.readFile(path.join(__dirname, pathname), (err, data) => {
      if (err) {
        res.end("Not Found");
        return;
      }
      res.write(data);
      res.end();
    });
  }
});
server.listen(3000, () => {
  console.log("Server running at http://localhost:3000");
});


```

# https（443）

保证数据在传输过程不被窃取和篡改，从而保证传输安全

### 对称加密

对称加密：产生一个密钥，可以用其加密，也可以用其解密
加密过程：信息+key=key-信息
解密过程：key-信息+key = 信息
常用算法：DES、3DES、AES、Blowfish等

### 非对称加密

非对称加密：产生一个对密钥（公钥私钥），一个用于加密，一个用于解密
加密过程：信息+公钥key=key-信息
解密过程：key-信息+私钥key = 信息
常用算法：RSA、Elgamal、Rabin、D-H、ECC等
