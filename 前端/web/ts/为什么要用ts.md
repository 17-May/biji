# 为什么要用ts

### JS开发中的问题

- 使用了不存在的变量、函数或者成员
- 把一个不确定的类型当作一个确定的类型处理
- 再使用null或者undefined的成员
- js 语言本身的特性，决定了该语言无法适应大型复杂的项目
- 弱语言：某个变量，可以随时更换类型
- 解释型：运行之后才能知道错误

### TS

TS是JS的*超集*，是一个*可选的*、*静态的* *类型系统*。

- 超集：TS拥有JS所有的功能，并且多一些功能
- 类型系统：对代码中所有的标识符（变量、函数、参数、返回值）进行类型检查
- 静态：类型检查发生的事件，在编译的时候，而不是运行时
- TS不参与运行时的类型检查
