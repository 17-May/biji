# 装饰器

`"experimentalDecorators": true, //启用实验性的装饰器`
`"emitDecoratorMetadata": true //在编译阶段将装饰器的元数据作为注释保留在输出文件中`
`@函数名`

### 类装饰器

```ts
function classDecorator(constructor: Function) {
  console.log("class decorator called");
}

@classDecorator
class TestClass {}
```

### 属性装饰器

属性装饰器是一个函数，有两个参数。

- 参数一：如果是实例属性，参数是类的原型。如果是静态属性，参数是类的本身
- 参数二：字符串类型，表示属性名

```ts
function aDecorator(target: any, propertyKey: string) {
  console.log(propertyKey);
  console.log(target);
}
class TestClass {
  @aDecorator
  a: number = 1;
  @aDecorator
  static b: string = "2";
}
```

### 方法装饰器

方法装饰器是一个函数，有三个参数。

- 参数一：如果是实例属性，参数是类的原型（对象类型）。如果是静态属性，参数是类的本身（类构造函数类型）
- 参数二：字符串类型，表示方法名(访问器属性名)
- 参数三：属性描述对象，js中Objec.defineProperty()中的描述对象

```ts
function fnDecorator( target: any, prototype: string, descriptor: PropertyDescriptor ) {}
function fnDecorator2( target: new (...args: any[]) => any, propertyKey: string, descriptor: PropertyDescriptor ) {}
class TestClass {
  @fnDecorator
  get fn(): string {
    return "test";
  }
  @fnDecorator2
  static fn2() {
    return "test";
  }
}
```

### reflect-metadata（第三方库）

引入`import "reflect-metadata"`

##### 声明

1. 声明式定义：需要放在具体定义的对象上
   - `Reflect.metadata(metadataKey,metadataValue)`
2. 命令式定义：需要给出具体的参数
   - `Reflect.defineMetadata(metadataKey,metadataValue,定义的元数据对象,propertykey?)`

##### 获取

`Reflect.getMetadata(metadataKey,定义元数据的对象):返回的metadataValue`

```ts
import "reflect-metadata";

@Reflect.metadata("test1", "test")
class TestClass {
  get fn() {
    return 123;
  }
}
Reflect.defineMetadata("test2", "test", TestClass);

console.log(Reflect.getMetadata("test1", TestClass));
console.log(Reflect.getMetadata("test2", TestClass));
```
