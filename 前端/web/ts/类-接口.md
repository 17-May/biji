# 类-接口

# 类

### 属性

使用属性列表来描述类中的属性

- 修饰可选：`属性?`
- 修饰只读：`readonly 属性`

#### 属性的初始化检查：`"strictPropertyInitialization": true`

##### 属性初始化位置

- 构造函数中
- 属性默认值

#### 访问修饰符

- public：默认访问修饰符，公开的，所有的代码均可引用
- private：私有的，只有在**类中**可以访问
- protected：受保护的，只能在**类中和子类**可以访问
- constructor：构造函数，new使用
- static：静态属性和静态方法，最好不使用this取值

### es2022新增私有属性

- `#属性名`

### 静态属性/方法和其他的区别

- 静态属性/方法转是存在类的属性上
- 其他属性和方法则是存在类的原型上

#### 访问器

用于控制属性的读取和赋值

- 设置器：get
- 读取器：set

```ts
class User {
  _age: number;
  gerder?: "男" | "女" = "男";
  private myName: string = "私有的";
  protected myAge: number = 18;
  //构造函数
  // public name : 语法糖 访问修饰符+属性。
  constructor(public name: string, age: number) {
    this.name = name;
    this._age = age;
  }
  // 访问器
  // 相当于 getAge
  get age() {
    return this._age;
  }
  set age(value: number) {
    this._age = value;
  }
}
let user = new User("张三", 18);
user.age = 2;
console.log(user.age);
```

### 继承

- super关键字可以调用父类构造函数

```ts
constructor() {
    super("Admin");
  }
```

### 抽象类(abstract)

- 只能被继承，不能被构建
- 将公共的东西抽离出来

### 混入

`Object.assign()`

```ts
class User {
  constructor() {
    console.log("User created");
  }
}
class Admin {
  constructor() {
    console.log("Admin created");
  }
}
const user = Object.assign({}, new User(), new Admin());
```

# 接口

接口：用于约束类、对像、函数的契约（标准）,规定程序要做什么不在其中实现的协议。

- `interface 名{}`
- 继承：`interface A extends B` A 继承于B

```ts
interface User {
  name: string;
  sayHello(): void;
  sayHello1: () => void;
}
interface User {
	（xxx）: xxx
}
```

### 接口和类型别名的区别

- 类型扩展
  - 类型别名没有继承只有交叉类型。会把相同类型的成员进行交叉
  - 接口有继承，子接口不能覆盖父接口的成员
- 逻辑
  - 类型运算首选类型别名
  - 接口是抽象的描述，不应该有复杂的逻辑，只是声明。
- 接口无法直接描述基本数据类型、元组和联合类型。都可以描述对象类型、函数类型、class类型。
