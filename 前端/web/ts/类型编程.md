# 类型编程

### 类型映射（索引签名类型）

`[key : 类型]:类型`

```ts
type User = {
  [key: string]: string;
};
let user: User = {
  name: "123",
  age: '13',
};

```

### keyof

- 获取类型的属性
- &{} 增加提示

```ts
type User1 = {
  // [key: string]: object;
  name: string;
  age: number;
};
type UserKey = keyof User1 & {};// & {} 增加提示
let user: UserKey = 'age' //属性
```

### in

- 属性属于xx设定的类型
- 必须在[]使用

```ts
type Name = "a" | "b" | "c";
type User = {
  [key in Name]: string;
};
```

### [] 运算符

常用方式

```ts
//获取数组的值做类型
let arr = ["name", "age", "tel"] as const;// ["name", "age", "tel"] 只读元组
type ArrType = typeof arr; // "name" | "age" | "tel"
```

### 类型判断

- 三元运算符进行判断
- `需要判断的类型 extends 判断的类型? true : false;`

### infer

类型推断，`(infer U)`。使用直接使用`U`

### 递归调用

```ts
type Str = "123456";
type StringType<T extends string> = T extends `${infer First}${infer Rest}`
  ? `${First} | ${StringType<Rest>}`//递归
  : "";
type Result = StringType<Str>; // "1 | 2 | 3 | 4 | 5 | 6"

```
