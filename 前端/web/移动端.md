# rem适配方案

- 1rem=根元素的字体大小
- 根元素字体大小 = 100 * 屏幕宽度 / 设计稿宽度

```js
const WIDTH = 750; //设计稿宽度
function setView() {
  document.documentElement.style.fontSize = (100 * screen.width) / WIDTH + "px";
  console.log((100 * screen.width) / WIDTH);
}
window.onorientationchange = setView; //设备旋转时调用
setView();

```

### PPI

- 每英寸的物理像素点数量

### dpi

- 每英寸所打印的点数或者线数，用来表示打印机打印分辨率
- 鼠标dpi 1200 1600 ...

### 设备像素比dpr

- px（css像素） = pt（逻辑像素） * dpr（像素比）
- `window.devicePixelRatio`获取dpr
