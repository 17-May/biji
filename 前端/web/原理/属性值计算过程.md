# 属性值计算过程

![[Pasted image 20240302155832.png]]

### 样式类型

- 作者样式表：自己写的样式
- 浏览器默认样式表：浏览器默认的样式

### 步骤

1. **确定声明值**：参考样式表中没有冲突的声明，作为css属性值
2. **层叠冲突** :对样式表有冲突的声明使用层叠规则，确定css属性值、
   1. **比较重要性**：作者样式表高于浏览器默认样式
   2. **比较特殊性**：比较权重
   3. **比较源次序**：后面代码覆盖前面代码
3. **使用继承**：对仍然 *没有值* 的属性，若可以继承，则继承父元素的值。
4. **使用默认值**：对仍然没有值的属性，使用默认值
