# 值和引用

### 基本数据类型

- string
- symbol
- number
- boolean
- undefined
- null
- bigint

### 引用数据类型

- object
  - array
  - function

### null和undefined

- typeof null打印出来的是object。在js中对象的二进制前三位是0，而null全是0，所以会被判断位object.
- null == undefined =>true

#### null

- 表示“无”的对象（空对象指针），转换数值时为0
- 作为函数的参数，表示该函数的参数不是对象
- 作为对象原型链的终点

#### undefined

- 表示“无”的原始值，转换数值时为NaN
- 变量被声明了，但是没有赋值时，就时undefined
- 调用函数时，应该提供的参数没有提供，该参数等于undefined
- 对象没有赋值的属性，该属性的值为undefined
- 函数没有返回值时，默认返回undefined

|类型|访问方式|比较方式|动态属性|变量赋值|

|原始值|值|值|无法添加|值|
|引用值|引用地址|地址|可以添加|地址|
