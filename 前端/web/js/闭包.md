# 闭包

### 含义

- 闭包是指在定义函数时，函数内部使用了外部的值，创建闭包。
- 自动形成的闭包，会自动销毁。
- 手动形成的闭包，无法自动销毁。如函数返回

```js
function aFn() {
  var b = 2;
  return function () {
    console.log(b);
  };
}
const fn = aFn();
fn();// 2
fn();// 2

```

### 作用

- 可以让外部环境访问到函数内部的局部变量
- 可以让局部变量保存下来，不随着上下文环境一起销毁

### 面试题

##### 闭包是什么？闭包的应用场景有哪些？怎么销毁闭包？

- 闭包是一个封闭的空间，里面存储了在其他地方会引用到的作用域的值，在js中是通过作用域链来实现的闭包
- 只要在函数中使用的外部的数据，就会形成闭包，这种情况无需关注，会自动销毁
- 手动创建的闭包，不会自动销毁

---

- 使用闭包可以解决全局变量污染的问题

---

- 手动创建的闭包可以将引用的变量设置为null,js在垃圾回收是会自动回收。
- 自动创建的闭包会自动销毁
