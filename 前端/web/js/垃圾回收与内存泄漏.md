# 垃圾回收与内存泄漏

### 什么是内存泄露

- 程序的运行需要内存，程序在运行时或者提出要求时，操作系统就必须给内存。
- 对于持续运行的程序，必须及时释放内存，不然可能会影响系统性能或者程序奔溃
- 不再用到的内存，如果没有及时释放，就叫内存泄露

### js 中的垃圾回收

- js 是具有自动垃圾回收机制
- 垃圾回收器会定期（周期性）找出那些不在继续使用的变量，然后释放其内存
- 过程不是实时的，其开销很大且会停止响应其他操作。
- 销毁的变量是局部变量，全局变量的生命周期是浏览器卸载页面才结束。
- 手动创建的闭包必须手动设置为null,该内存才会被回收

### 面试题

##### 请介绍一下js中的垃圾回收机制

- js 具有自动垃圾回收机制，垃圾回收机制会周期性的执行
- js 常见的垃圾回收方式：**标记清除**、**引用计数**

###### 标记清除

- 当变量进入环境时，将这个变量标记为“进入环境”。当变量离开时，将这个变量标记为”离开环境“。标记”离开环境“的就回收

###### 引用计数

- 跟踪记录每个值被引用的次数，引用一次就加1，清除一次就减1。引用次数为0就无法访问了，垃圾回收器下一次执行时，清除为0的值所占的内存
