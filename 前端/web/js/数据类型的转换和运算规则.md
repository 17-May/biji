# 数据类型的转换和运算规则

# 数据类型的转换

- 原始转数字
  - true:1
  - false:0
  - null:0
  - undefined:NaN
  - string
    - 空字符串：0
    - 去掉引号，不是数字NaN
- 所有类型转bool
  - null:false
  - undefined:false
  - number
    - 0:false
    - NaN:false
    - 其他:true
  - string
    - 空字符串:false
    - 其他:true
  - 对象：true
- 原始转字符串
  - null:'null'
  - undefined:'undefined'
  - number:'数字'
  - boolean
    - true:'true'
    - false:'false'
- 对象转原始
  - 调用valueOf->得到的是对象？重新调用toString->得到的还是对象？报错

# 运算规则

- 算术运算（+ - * / % ++ --）
  - 转换原始类型
    - 转换为数字，然后运算
    - 特殊情况：NaN和任何类型运算都是NaN
    - 特殊情况：x+y，x和y 有一个是字符串则拼接
- 比较运算（> < >= <= == != === !== ）
  - > < >= <=：转换成原始类型
    >

    - 转换数字，比较
    - 特殊情况：两端都是字符串，比较字典顺序（一个一个比较，相同则往后比较，第一个不相同时则停止。A<a）
    - 特殊情况：两端存在NaN，一定为false
  - ===
    - 类型和值必须相同
    - 特殊情况：存在NaN,返回false
  - ==
    - 两端相同，比较值
    - 两端都是原始类型，转换成数字比较
    - 一端是原始类型，一端是对象类型，把对象转换成原始类型后比较
    - 特殊情况：两端存在NaN，一定为false
  - != !== :对等相反
- 逻辑运算（! && || ?:-三元）：转换为Boolean
  - x && y
    - x 为false,返回 x
    - x 为true,返回 y
  - x || y
    - x 为false,返回 y
    - x 为true,返回 x

```js
let a = {
  i: 1,
  valueOf: function () {//方案一
    return a.i++;
  },
  toString: function () {//方案二
    return a.i++;
  },
};
if (a == 1 && a == 2 && a == 3) {
  console.log("a is 1, 2 or 3");
}
```
