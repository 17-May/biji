### option Api 和composition Api

- option Api会将相同任务相关的内容分配到不同的配置中
- composition Api 会将相关任务的内容分配到一起（高内聚）

### composition Api

#### setup

- 所有生命周期钩子函数之前执行
- 没有this（undefined）

##### ref() 响应式数据

- template中读取变量的值是从实例对象中获取
- setup 中获取变量是获取到变量的对象，值在对象的value中

##### watchEffect()[​](https://cn.vuejs.org/api/reactivity-core.html#watcheffect)

立即运行一个函数，同时响应式地追踪其依赖，并在依赖更改时重新执行

##### computed

- vue2 可以使用get和set的方法。可读可改
- vue3 建议只使用get方法，不使用set方法。只读不改
