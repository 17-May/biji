# 路由

# histroy

### pushState

- `histroy.pushState(data,'',url)`
- 修改地址栏地址，页面不刷新，内容小于  640k
- 会新建一个历史记录

### popState

- `histroy.popState`
- 返回、前进、跳转，才会触发。回调事件

### replaceState

- `history.replaceState`
- 修改当前url，不会创建新的历史记录

### back

- `history.back`
- 返回后一个url

### forward

- `history.forward`
- 返回前一个url

### go

- 跳转到指定的url

# router实现

```js
// router.js
import { createContext, useEffect, useState } from "react";

// 什么路径渲染什么组件，组件和路径一一对应
// Router不一定是BrowserRouter的子节点
function Router(props) {
  const { path: componentPath, component: Component } = props;
  return (
    <RouterContext.Consumer>
      {(router) => {
        return componentPath === router.path ? <Component /> : null;
      }}
    </RouterContext.Consumer>
  );
}
// 为了下发状态，不会受shouldComponentUpdate的影响
const RouterContext = createContext();
// 将react的生命周期和history结合起来
// 再将path和Router进行关联，对path进行管理
function BrowserRouter(props) {
  // path管理
  const [path, setPath] = useState(() => {
    //首次渲染，获取到对应路由
    const { pathname } = window.location;
    return pathname || "/";
  });
  function handlePopstate(e) {
    const { path } = e.state;
    console.log(path);
    setPath(path);
  }
  useEffect(function () {
    window.addEventListener("popstate", handlePopstate);
    return () => {
      window.removeEventListener("popstate", handlePopstate);
    };
  }, []);
  // useEffect(function componentDidMount() {
  //   window.addEventListener("popstate", handlePopstate);
  //   return function componentWillUpdata() {
  //     window.removeEventListener("popstate", handlePopstate);
  //   };
  // });
  // const handlePopstate = function (event) {
  //   console.log("handlePopstate", event);
  //   const { pathname } = window.location;
  //   setPath(pathname);
  // };

  const goPath = function (path) {
    setPath(path);
    window.history.pushState({ path }, null, path);
  };
  const goBack = function () {
    window.history.go(-1);
  };
  const routerData = {
    path,
    goPath,
    goBack,
  };
  return (
    <RouterContext.Provider value={routerData}>
      {props.children}
    </RouterContext.Provider>
  );
}

export { BrowserRouter, Router, RouterContext };

```

### 一级路由

- 需要在path中携带"/地址"
- 后面层级的路由不需要携带"/"

### Outlet

子组件占位符

```js
	<Route path="/" element={<Warp />}>
          {/* index 默认渲染的子组件 需要在父组件中配置Outlet 占位符*/}
          <Route index element={<Home />}></Route>
    </Route>
```

### 动态路由

- `path=":id"` 可以认为是url地址占位符
- 如果路由名称相同，比较优先级。v6中确定好的路由优先级最高

### link

- 跳转路由
- `<Link to="/about">about</Link>`

### useParams

- `const info = useParams();`
- 获取动态路由

### useSearchParams

- 获取url的参数和设置参数
- 参数一：获取参数数量(可以使用原型上的方法获取参数的值)
- 参数二：对参数进行操作

```js
const [urlSearchParams, setUrlParams] = useSearchParams();
  console.log(urlSearchParams.get("name"));
  function handleClick() {
    setUrlParams({
      name: 1,
      age: 2,
    });
  }
```
