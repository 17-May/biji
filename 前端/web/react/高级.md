# context

提供了一个无需每层组件手动添加props，能在组件数间进行数据传递的方法。会使组件复用性变差

1. 创建context
2. 使用context.Provider进行包裹
3. 在组件中使用contextType关键字

```js
//默认值
const ThemeContext = React.createContext("dark");
class App extends React.Component {
  render() {
    return (
      <ThemeContext.Provider value="linke">
        <TButton></TButton>
      </ThemeContext.Provider>
    );
  }
}
class TButton extends React.Component {
  render() {
    return <ThemeButton></ThemeButton>;
  }
}
class ThemeButton extends React.Component {
  //contextType关键字
  static contextType = ThemeContext;
  handleClick = () => {
    this.context = 'dark'
  };
  render() {
    return (
      <button theme={this.context} onClick={this.handleClick}>
        我是按钮
      </button>
    );
  }
}
```

### 响应变化

- 生产消费者模型
- 组件只要订阅了contextType，就是消费者，消费者可以订阅生产者。生产者发生变化通知消费者
- context可以无视中间组件的组织渲染，依然可以响应生产者数据的变化
- props无法无视中间组件的组织渲染，必须是一层一层接收渲染

### context.Provider

- 不使用provider可以拿到默认值
- value=undefined 不会生效

### context.Consumer

可以让函数式组件也拥有消费者的响应变化能力

```js
function ThemeButton() {
  return (
    <ThemeContext.Consumer>{(value) => <h1>{value}</h1>}</ThemeContext.Consumer>
  );
}
```

### 注意

- context会根据标识来决定何时进行渲染（本质上是value属性值的浅比较），每次都是新的对象，导致消费者一直加载
- 不要在value中直接绑定属性，要在state中引用

```js
<ThemeContext.Provider value={{name:1}}></ThemeContext.Provider>//不用 消费者会一直加载
<ThemeContext.Provider value={this.state.name}></ThemeContext.Provider>//推荐 消费者不会一直加载 
```

# 错误边界（Error Boundaries）

- 部分UI的JavaScript错误不应该导致整个应用崩溃，为解决这个问题，React16引入——错误边界
- 错误边界是一种React组件，可以捕获并打印发生在其子组件树任何位置的JavaScript错误，并且会渲染备用UI。
- 错误边界在渲染期间、生命周期方法和整个组件树的构造函数中捕获错误

```js

//错误边界组件 通用组件
class ErrorBoundary extends React.Component {
  constructor(props) {
    super(props);
    this.state = {
      hasError: false,
    };
  }
  // 发生错误的时候，会触发
  static getDerivedStateFromError(error) {
    //更新state 使下一次渲染能够显示降级后的UI
    console.log(error);
    return { hasError: true };
  }
  componentDidCatch(error, errorInfo) {
    console.log(error, errorInfo);
    // 错误日志上报给服务器
    // logErrorToMyService(error, errorInfo);
  }
  render() {
    if (this.state.hasError) {
      //自定义降级后的UI并渲染
      return <h1>something went error</h1>;
    }
    return this.props.children;
  }
}
```

##### 注意

错误边界无法捕获以下场景中产生的错误：

1. 事件处理
2. 异步代码
3. 服务端渲染
4. 自身抛出的错误（不是子组件错误）

# refs

允许访问ＤＯＭ节点或者在render中创建React元素

- constructor中拿到的ref是空，无法拿到ref。需要在componentDidMount之后才能获取。
- 函数式组件无法直接使用ref

```js
class App extends React.Component {
  constructor() {
    super();
    this.div_ref = React.createRef();//创建ref
  }
  handleClick = () => {
    console.log(this.div_ref);
  };
  render() {
    return (
      <div ref={this.div_ref}>
        <button type="button" onClick={this.handleClick}>
          点击
        </button>
      </div>
    );
  }
}
```

### 子组件回调函数传递ref给父组件

```js
class Home extends React.Component {
  render() {
    return <input type="text" ref={this.props.inputRef} />;
  }
}

class App extends React.Component {
  handleCallBack = (el) => {
    console.log(el);
    this.inputElement = el;
  };

  render() {
    return (
      <div>
        <Home inputRef={this.handleCallBack}></Home>
        <Home inputRef={(el) => (this.inputElement = el)}></Home>
      </div>
    );
  }
}
```

### refs转发

`React.forwardRef()`

```js
const FancyButton = React.forwardRef((props, ref) => {
  return <button ref={ref}>{props.children}</button>;
});

class App extends React.Component {
  constructor() {
    super();
    this.fancyButtonRef = React.createRef();
  }
  componentDidMount() {
    console.log(this.fancyButtonRef);
  }

  render() {
    return (
      <div>
        <FancyButton ref={this.fancyButtonRef}>
          <h1>点击</h1>
        </FancyButton>
      </div>
    );
  }
}
```

### 在高阶组件中转发refs（HOC）

高阶组件：一个函数接收一个组件，并修改组件，最后返回一个新的组件

```js
function logProps(Component) {
  class LogProps extends React.Component {
    render() {
      const { forwardRef, ...arg } = this.props;
      return <Component ref={forwardRef} {...arg}></Component>;
    }
  }
  // 接收外部传入的ref和props属性
  return React.forwardRef((props, ref) => {
    return <LogProps {...props} forwardRef={ref}></LogProps>;
  });
}
class ChildComponent extends React.Component {
  constructor() {
    super();
    this.state = {
      name: 0,
    };
  }
  render() {
    return <button>点击</button>;
  }
}
const Child = logProps(ChildComponent);
class App extends React.Component {
  constructor() {
    super();
    this.child_ref = React.createRef();
  }
  componentDidMount() {
    console.log(this.child_ref);
  }
  render() {
    return (
      <div>
        <Child ref={this.child_ref}/>
      </div>
    );
  }
}
```

# 高阶组件

- 只是一种基于React的组合特性而形成的设计模式
- 接收一个组件，返回一个新的组件
- with开头的基本都是HOC高阶组件

##### 注意

1. 不要去修改组件原型（纯函数）
2. 不要再render方法中使用，不要再render中定义
3. 静态属性和方法无法直接在调用高阶函数时使用，需要在高阶函数中重新定义/赋值

###### 获取静态属性或者方法

```js
// 获取静态属性/方法
import hoistNonReactStatics from "hoist-non-react-statics";
function withHoc(Component) {
  class Result extends React.Component {
    //方式一 直接赋值
    // static getName = Component.getName;
    render() {
      return <Component></Component>;
    }
  }
  // 方法二
  // 返回的组件 传入的组件 
  hoistNonReactStatics(Result, Component);
  return Result;
}
class App extends React.Component {
  static getName = () => {
    console.log("getname");
  };
  render() {
    return;
  }
}
const withApp = withHoc(App);
//获取组件的静态方法
withApp.getName();
```

##### 发布订阅模型

```js
class DataSource {
  constructor() {
    this.listener = [];
  }
  addChangeListener(callback) {
    this.listener.push(callback);
  }
  removeChangeListener(data) {
    const index = this.listener.indexOf(data);
    this.listener.splice(index, 1);
  }
  publish(data) {
    for (let i = 0; i < this.listener.length; i++) {
      const listener = this.listener[i];
      listener(data);
    }
  }
}
const dataSource = new DataSource();

dataSource.addChangeListener((data) => {
  console.log("第一人", data);
});
dataSource.addChangeListener((data) => {
  console.log("第二人", data);
});
dataSource.publish('你树')
setTimeout(() => {
  dataSource.publish('你树1')
}, 1000);
```

# Portal

- 将需要渲染的任意组件，插到页面中的任何dom中
- ReactDom.createPortal(组件，DOM)
- 事件冒泡遵循react组件的生命周期

```js
class Home extends React.Component {
  render() {
    return ReactDom.createPortal(
      <button>点击</button>,
      document.querySelector("#root")
    );
  }
}
class App extends React.Component {
  render() {
    return (
      <div>
        <h1>111</h1>
        <Home></Home>
      </div>
    );
  }
}
```
