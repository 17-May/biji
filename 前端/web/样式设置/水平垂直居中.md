# 水平垂直居中

# 1.知道元素宽高

```CSS
.box{
	width: 100vw;
	height: 100vh;
	background: pink;
  }

  .item{
	width: 500px;
	height: 500px;
	background: green;
	position: absolute;
	margin-top: -250px;
	margin-left: -250px;
	top: 50%;
	left: 50%;

  }
```

# 2. margin:auto;

```CSS
.box{
	width: 100vw;
	height: 100vh;
	background: pink;
	position: relative;
  }

  .item{
	width: 500px;
	height: 500px;
	background: green;
	position: absolute;
	top: 0;
	left: 0;
	right: 0;
	bottom: 0;
	margin: auto;
  }
```

# 3.transform

```CSS
.box{
	width: 100vw;
	height: 100vh;
	background: pink;
	position: relative;
  }

  .item{
	width: 500px;
	height: 500px;
	background: green;
	position: absolute;
	top: 50%;
	left: 50%;
	transform: translate(-50%,-50%);
  }
```

# 4.flex

```CSS
.box{
	width: 100vw;
	height: 100vh;
	background: pink;
	display: flex;
	align-items: center;
	justify-content: center;
  }

  .item{
	width: 500px;
	height: 500px;
	background: green;
  }
```
