# Webgl

- 是一种用于在web浏览器中实现交互式3D图形的JavaScriptAPI。
- Webgl可以直接与Html5标签Canvas进行集成，并且可以是通过GPU来资讯高性能图形计算。
- Webgl的本质——JavaScript操作OpenGL接口。webgl基于opengl es协议。

### Webgl和Threejs的关系？

- webgl是浏览器提供的底层API，和OpenGL结合。
- threejs实际上是基于webgl进行封装的上层框架。

### Webgl和Webgpu的区别？

- webgl版本：为什么到2024年就不前进了，兼容性，硬件，平台。
- 现在的webgl已经不能充分发挥出现代显卡的性能，所以诞生了webgpu
- webgl是基于opengl es的图形API，是一种高级别的API
- webgpu是一种低级别的、跨平台的图形和计算的API，可以让web应用程序直接访问gpu的底层硬件资源。

# 渲染管线

- 将3D数据转换成2D页面

### 图形领域的三要素

1. 点
2. 线
3. 三角形

### WebGl渲染管线

- cpu获取js提供的图像顶点信息（3D数据），然后将数据传给gpu
- 首先进入顶点着色器阶段，利用gpu的并行计算优势对顶点逐个进行坐标变化
- 然后进入图元装配阶段，将顶点按照图元类型组装成图形
- 接下来到光栅化阶段，光栅化阶段将图形用不包含颜色信息的像素填充
- 在之后进入片元着色器阶段，该阶段为像素着色，并最终显示到屏幕上

# GLSL

着色器语言，OpenGl Shader(Shading) Language。基于OPENGL，给GPU进行更深层次的编程，实现各种各样炫酷的效果

- .frag：片元着色器
- .vert：顶点着色器

##### glsl在js中存在的形式

实际上就是字符串

# 第一个webgl例子

```javascript
import frag from "./glsl/index.frag";
import vert from "./glsl/index.vert";

/** @type{HTMLCanvasElement} */
const canvas = document.querySelector("#canvas");
const gl =
  canvas.getContext("webgl") || canvas.getContext("experimental-webgl");

// 流程1 创建顶点着色器
const vertexShader = gl.createShader(gl.VERTEX_SHADER);
// 将着色器源代码传递给着色器对象
gl.shaderSource(vertexShader, vert);
// 编译着色器
gl.compileShader(vertexShader);

// 流程2 创建片元着色器
const fragmentShader = gl.createShader(gl.FRAGMENT_SHADER);
// 将着色器源代码传递给着色器对象
gl.shaderSource(fragmentShader, frag);
// 编译着色器
gl.compileShader(fragmentShader);

// 流程3 创建着色器程序
const program = gl.createProgram();
// 附着顶点着色器
gl.attachShader(program, vertexShader);
// 附着片元着色器
gl.attachShader(program, fragmentShader);
// 链接着色器
gl.linkProgram(program);
// 链接成功后使用
gl.useProgram(program);

// 流程4 绘制
// 创建顶点数据
gl.clearColor(0.0, 0.0, 0.0, 2.0);
// 清空画布
gl.clear(gl.COLOR_BUFFER_BIT);
// 绘制点
// 参数一:绘制方式
// 参数二:从哪里开始
// 参数三:绘制几个点
gl.drawArrays(gl.POINTS, 0, 1);

```
